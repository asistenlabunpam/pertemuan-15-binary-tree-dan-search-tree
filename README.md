# Pertemuan 15: Binary Tree dan Binary Search Tree (BST)

## Deskripsi
Materi Pertemuan 15 berfokus pada struktur data Pohon Biner (Binary Tree) dan Pohon Pencarian Biner (Binary Search Tree / BST). Ciri utama BST adalah elemen pada subtree kiri selalu lebih kecil dari node induk, dan elemen pada subtree kanan selalu lebih besar atau sama dengan node induk.

## Program yang Tersedia
1. `01_binary_search_tree_dasar.py`: Pembuatan kelas `Node` dan `searchtree` dengan metode `create`, `bft` (Breadth-First Traversal), `inorder`, `preorder`, dan `postorder`.
2. `02_binary_search_tree_pencarian.py`: Implementasi fungsi rekursif `insert` dan `search` pada BST dengan kompleksitas rata-rata $O(\log N)$.

## Cara Menjalankan
Jalankan file yang diinginkan:
```bash
python 01_binary_search_tree_dasar.py
python 02_binary_search_tree_pencarian.py
```
